核对日期：2026-09-23。官网已部署到用户的华为云服务器，仅提供私有预览，尚未公开上线。

后续更新：用户指定的旧域名 `milo.huangtangai.top` 已通过原 Vercel 项目公开发布新版官网与本地 Web 体验，详见 [Vercel 发布记录](vercel-web-release-2026-09-23.md)。本页以下的“未公开上线”仅描述华为云和 `milomood.xyz`。

## 已完成

- 官网沿用现有深色星空、紫粉色调、真实 logo，以及全部 15 种情绪星球；支持点击点亮星球与手机布局。
- 3D 更新：新增有纵深视差的星空与银河；主星球通过 WebGL 射线与球面相交实时绘制，复用现有表情矢量路径，具备表面纹理、光照、球面表情、大气光和前后遮挡的轨道。支持拖动或方向键旋转、靠近/退后、重置视角，以及“仰望星空”沉浸模式中的 15 种星球切换、暖光与暂停控制。
- 沉浸模式使用原生模态对话框，支持 Escape 退出与返回入口焦点；手机情绪选择条可以横向滚动。尊重减少动态效果设置，后台或离屏停止星球绘制，WebGL 不可用时展示原版图案。
- `/` 为官网，`/app` 为 Web 体验，`/privacy` 为实际数据处理说明。
- Web 体验默认先选择本地引导或 AI；本地使用不依赖 AI、登录或网关。
- AI 仅在用户同意后，经同源 `/api` 访问服务器，再由服务器调用 MiniMax。任何 API 密钥及网关令牌均不进入浏览器构建产物。
- 本地与 AI 提示以简短提问为主；用户表示暂停时立即接受。本地日记保留用户原话。
- 保存的日记属于当前浏览器；不同设备、浏览器或访问地址之间不会自动同步。
