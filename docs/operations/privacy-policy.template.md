MILO 是个人情绪日记与回忆记录工具，不提供医疗诊断或治疗。请在使用前阅读本政策和用户协议。你可以在首次提示、登录页及“我的—关于 MILO”中查看全文；文档保存在应用内，离线也能阅读。

## 一、你的同意与功能范围

首次使用或本版政策更新后，我们会先展示隐私说明。你主动点击“同意隐私政策与用户协议并继续”后才能进入登录或日记功能；暂不同意时仍可阅读协议，不会因此删除已有本机数据。应用在取得本版同意前不初始化华为认证服务，也不调用其登录、验证码等功能。我们在本机保存已同意的政策版本号。

本版本不提供 AI 生成、大模型连接或付费会员功能，不将日记或对话发送给大模型服务商。本地的回忆引导和文字整理不依赖 AI 或联网。首次邮箱登录、发送验证码、修改密码及注销账号需要联网；已成功登录并同意本政策后，日记功能可离线使用。

## 二、账号信息与华为认证服务

为提供邮箱注册、登录、密码管理和账号注销，我们集成华为软件技术有限公司提供的 AGC 认证服务 SDK（包名 @hw-agconnect/auth）。你主动提交的邮箱、验证码或密码由该认证服务验证；未注册邮箱可通过验证码创建账号。应用自身在本机保存账号标识 UID、邮箱及登录方式，不在日记中保存你提交的密码。认证 SDK 另行管理登录凭证及认证缓存。

根据华为对该 SDK 的说明，认证服务涉及可变设备标识符 AAID、账号信息、认证提供方用户标识 ProviderUid、AGC 用户标识 AgcUid，以及应用包名、应用版本号等认证所需信息。本应用启用的是邮箱认证，不提供手机号登录或华为账号授权登录，也不把你选择的本地头像上传给认证服务。SDK 的全部能力范围可能还包含其他登录方式使用的手机号、昵称和头像；这不表示 MILO 启用了这些登录方式。

## 三、情绪记录、日记和草稿

你选择的心情和标签、时间标记、输入文字、回忆对话、日记内容及创建时间保存在当前设备的应用私有存储中。未完成的草稿也在本机保存，便于下次继续。MILO 没有自建日记云同步服务，不把这些记录上传到 MILO 服务器或认证服务。

本机日记并非按登录账号隔离；在同一设备切换账号仍可能看到已有本机记录。退出登录不会清除日记。请避免与他人共用未锁定的设备，并在移交设备前导出需要的记录、删除本机数据。

应用启用了 HarmonyOS 系统备份与恢复能力。若你使用系统备份、设备迁移等功能，相关副本的存放及恢复由系统服务和你的系统设置管理，并非 MILO 账号云同步。

## 四、头像、导出和卡片图片

默认头像为内置星球风格图案。更换头像时，应用通过系统照片选择器访问你主动选中的一张图片，并复制到应用私有目录用于本机显示，不上传头像，也不读取整个相册。你可在“我的”恢复星球头像；图库原图不会随之删除。

在“我的—回忆与数据”中，你可将已保存的日记、情绪及对话导出为 Markdown 或 JSON，自行选择文件保存位置。导出不包含账号密码或 API Key，但包含你的记录内容，请妥善保管。未保存的草稿不属于日记导出范围。若所选保存位置由其他云盘或系统服务提供，相关副本由该服务按你的选择处理。

保存回忆卡片时，应用先在本机缓存目录生成包含记录内容的 PNG 图片，再通过系统授权保存入口写入图库。应用不主动上传这些图片。已保存到图库、导出到文件或随后由你分享的副本需要由你另行管理和删除。

## 五、权限和语音输入

互联网权限：用于邮箱认证、验证码、密码管理和账号注销；点击外部链接时，由相应应用访问该网页。本版本不通过互联网发送日记进行 AI 处理。
振动权限：用于操作时的轻触反馈。
麦克风权限：仅在你主动使用语音输入时申请。拒绝或在系统设置中撤回后，仍可正常打字记录。

语音输入使用 HarmonyOS Core Speech Kit 的中文离线短句识别模式。MILO 不主动生成录音文件，不将音频上传到 MILO 或大模型服务；识别文字进入输入区域，你可检查、编辑后再提交。识别能力和可用语言资源由设备系统提供。

头像选取、日记导出和卡片保存使用系统选择器或授权保存入口。应用不申请相机、通讯录或位置信息权限，不申请读取整个图库的权限。

## 六、保存、安全与删除

本机日记和草稿没有自动到期删除设置，会保留到你删除记录、成功注销账号或清除应用数据等操作为止。认证信息由华为认证服务按提供认证所需的期限及其适用规则管理；我们不会承诺无法核实的第三方即时删除或固定保留天数。

应用利用系统应用私有存储保存本地记录，认证请求通过 SDK 的安全网络连接发送。请设置设备锁屏并妥善保护导出文件。任何系统均不能保证绝对安全；发现隐私或安全问题可联系本政策列明的邮箱。

删除单篇记录：进入“回忆长廊”，打开记录详情，点击“放下”并确认。
注销账号：进入“我的”，点击“注销账号”并确认。邮箱账号需联网完成华为认证账号删除，成功后清除此设备的登录状态、日记和草稿，并清理当前账号的本地头像设置。若云端注销结果无法确认（例如请求中断或确认状态未能保存），应用保留本机记录并提示联系 1972375139@qq.com 核对，不会直接宣告云端账号已注销。你也可以先导出记录，再单独确认“仅清理本机数据并退出”；此操作不代表云端账号已注销。
若云端注销成功但本机清理未完成，应用会保留“待清理”状态，显示重试入口；重新打开应用也可继续清理，不会把未完成的清理显示为已成功。
清除本机数据：通过系统的应用存储管理功能清除应用数据；这不等同于注销云端认证账号。
退出登录：只结束登录，不删除本机日记或云端账号。

注销不会自动删除已导出文件、图库图片、接收方的分享副本或系统备份。你需在对应位置删除这些副本。应用也不提供从服务器恢复已删除日记的能力。

## 七、你的权利、未成年人及联系

你可在应用内查阅、复制导出或删除记录，更换头像，使用邮箱验证码修改密码，或注销账号。需查询、更正、删除认证信息，撤回同意或处理无法在应用内完成的请求时，可联系 1972375139@qq.com；我们会在必要身份核验后依法处理。请勿通过普通邮件发送密码或验证码。撤回使用同意后可停止使用并注销账号；麦克风权限可直接在系统设置中撤回。

未成年人应在监护人指导下阅读并使用本应用。若你未满十四周岁，应由监护人同意后使用；监护人如发现相关信息被不当处理，可联系我们协助处理。MILO 的记录和引导不能替代专业医疗帮助。

本政策如发生个人信息处理目的、方式或范围的重大变化，我们会更新版本、在应用中告知，并在需要时重新征得同意。当前版本可随时从应用中的协议入口查看。
